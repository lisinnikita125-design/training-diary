# Progressor — AI Performance System

> Персональный AI-коуч для силовых тренировок.
> **Train smarter. Recover better.**

## 🚀 Demo
https://nikitalisin.pythonanywhere.com

## ✨ Возможности
- 7 вкладок: Тренировка, История, Прогресс, Сравнение, Статистика, AI-тренер, Мой прогресс
- AI с памятью прошлых рекомендаций
- Индекс готовности и индекс прогресса
- Вес тела и замеры с графиками
- PWA — устанавливается на iPhone

## 🛠 Стек
Flask · SQLite · YandexGPT · Chart.js · PWA

## 🚀 Запуск локально
```bash
git clone https://github.com/lisinnikita125-design/training-diary.git
cd training-diary
pip install flask werkzeug
python3 database.py
python3 main.py
```
